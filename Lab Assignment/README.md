#   About me Form GUI - Tamana Bashardost, Sabrina Kessler, Selena Persaud

### Description
This application is a simple About me form program that mimics the front end of a text form.

The program can:
- Take user input from text field
- Change the center title label when submit is clicked
- let the user type in the text area
- Prints user input + title into the terminal
- Clear the text fields when Clear button is clicked
- Exit the program when Exit button is clicked
